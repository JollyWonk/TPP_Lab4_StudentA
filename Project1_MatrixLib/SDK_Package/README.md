# Контракт динамічної бібліотеки MatrixLib (v1.0) — Варіант 5

## 1. Загальні відомості
- **Назва бібліотеки:** `MatrixLib`
- **Версія API / DLL:** 1.0
- **Призначення:** Матричний аналіз дійсних матриць: обчислення визначника (детермінанта), рангу, оберненої матриці та перевірка на виродженість.
- **Цільова платформа:** Windows x64.
- **Сумісність зв'язування:** Підтримується неявне (load-time через `.lib`) та явне (run-time через WinAPI: `LoadLibrary` / `GetProcAddress`).
- **ABI:** C-сумісний (`extern "C"`), відсутнє С++ декорування імен (Name Mangling).
- **Формат представлення матриць:** Двовимірні матриці зберігаються у безперервному одновимірному масиві дійсних чисел (`const double*`) за рядками (row-major order). Елемент на перетині рядка $i$ та стовпця $j$ розташований за індексом:
  $$\text{index} = i \cdot \text{cols} + j$$

---

## 2. Специфікація функцій (API)

### 2.1. determinant
```c
double determinant(const double* matrix, int n);
```
- **Призначення:** Обчислення визначника (детермінанта) квадратної матриці порядку $n \times n$ методом Гаусса з вибором головного елемента.
- **Параметри:**
  - `matrix` (`const double*`): вказівник на одновимірний масив елементів матриці розміром $n \cdot n$.
  - `n` (`int`): порядок квадратної матриці ($n > 0$).
- **Результат:** Дійсне число — значення визначника $\det(A)$.

---

### 2.2. isSingular
```c
int isSingular(const double* matrix, int n);
```
- **Призначення:** Визначення, чи є квадратна матриця $n \times n$ виродженою (сингулярною, тобто $\det(A) = 0$).
- **Параметри:**
  - `matrix` (`const double*`): вказівник на матрицю.
  - `n` (`int`): порядок квадратної матриці ($n > 0$).
- **Результат:**
  - `1` — матриця вироджена ($\det(A) = 0$ з точністю до $\varepsilon = 10^{-9}$);
  - `0` — матриця невироджена ($\det(A) \neq 0$);
  - `-1` — помилка вхідних даних.

---

### 2.3. rank
```c
int rank(const double* matrix, int rows, int cols);
```
- **Призначення:** Обчислення рангу прямокутної або квадратної матриці розміром $rows \times cols$ методом прямого ходу Гаусса.
- **Параметри:**
  - `matrix` (`const double*`): вказівник на масив елементів матриці розміром $rows \cdot cols$.
  - `rows` (`int`): кількість рядків ($rows > 0$).
  - `cols` (`int`): кількість стовпців ($cols > 0$).
- **Результат:** Ціле невід'ємне число від `0` до $\min(rows, cols)$ — ранг матриці. При некоректних даних повертає `-1`.

---

### 2.4. inverse
```c
int inverse(const double* matrix, int n, double* outMatrix);
```
- **Призначення:** Знаходження оберненої матриці $A^{-1}$ для заданої квадратної матриці $n \times n$ методом Гаусса-Жордана.
- **Параметри:**
  - `matrix` (`const double*`): вказівник на вихідну матрицю $n \times n$.
  - `n` (`int`): порядок матриці ($n > 0$).
  - `outMatrix` (`double*`): попередньо виділений викликаючою програмою буфер пам'яті розміром щонайменше $n \cdot n$ елементів типу `double` для запису результату.
- **Результат:**
  - `1` — успішне обчислення оберненої матриці;
  - `0` — матриця вироджена (оберненої матриці не існує);
  - `-1` — помилка вхідних даних (нульовий вказівник або некоректний розмір).

---

## 3. Обмеження та контракт взаємодії (Preconditions & Postconditions)

### Передумови (Preconditions):
1. Вказівники `matrix` та `outMatrix` не повинні бути `nullptr` / `NULL`.
2. Розміри матриць повинні бути строго додатними: $n > 0$, $rows > 0$, $cols > 0$.
3. Для функції `inverse` буфер `outMatrix` повинен мати виділену пам'ять розміром не менше $n \cdot n \cdot \text{sizeof}(double)$.

### Поведінка у граничних випадках (Edge Cases):
- При передачі `nullptr` замість вказівника на масив:
  - `determinant` повертає `NaN` (`std::numeric_limits<double>::quiet_NaN()`).
  - `isSingular`, `rank`, `inverse` повертають `-1`.
- При передачі недопустимих розмірів ($n \le 0$, $rows \le 0$, $cols \le 0$):
  - `determinant` повертає `NaN`.
  - `isSingular`, `rank`, `inverse` повертають `-1`.
- Усі функції гарантують безпеку від аварійного завершення програми (відсутність падінь, Access Violation чи Segfault).

---

## 4. Керування пам'яттю та ресурсами
- Бібліотека **не виділяє** ресурси, які вимагали б ручного звільнення користувачем через спеціальні API-функції.
- Пам'ять для вихідного результату функції `inverse` виділяється та звільняється безпосередньо клієнтською програмою.
